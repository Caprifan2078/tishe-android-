## QA Web v0.2.5 — 2026-11-10

Исправлена гонка подтверждения: ответ сохраняется в зашифрованном localStorage до автоматического перехода к следующему вопросу и выводу. При ошибке записи прежнее значение восстанавливается, кнопки временно блокируются. Формат JSON, PBKDF2, AES-GCM и localStorage key не изменены.

Проверка JavaScript: 48 модулей (включая PHQ-4 и IPIP) + четыре маршрута 40/150/300/500; каждый даёт `Итог теста`, объяснение, следующий шаг и правильный экран результата. Дополнительно 18+ PHQ-4 и откат при имитированной ошибке шифрования. Browser rendering на iOS/Android устройстве не проверен; QA использует Node VM и реальный расчёт JavaScript/HTML.
