# Тише — Android

Офлайн-приложение для эмоциональной самопомощи и изучения собственных эмоций. Не является диагностикой и не заменяет психолога, врача или экстренную помощь.

## Версия 0.22.0 — единый Суперкомпас

- Один экран объединяет **общую диаграмму 18 чувств**, отдельные шесть шкал по ответам на начальный опрос, отметки текущих эмоций и варианты поддержки.
- **Осторожные подсказки** выводятся из конкретных самозаписанных отметок (4–5 из 5) и/или по минимум трём ответам темы опроса (среднее от 3/4). Это авторские эвристики, **не валидированная психометрия и не медицинский скрининг**. При недостаточных данных подсказка не создаётся.
- Отображается объяснение, какие ответы стали основанием для каждой подсказки; максимум три темы одновременно, чтобы не перегружать человека.
- Вопросы о сложных событиях доступны только по желанию. Никаких выводов о наличии или источнике психологической травмы, диагнозов и принудительного раскрытия опыта.
- **Не смешивать** 0–5 текущих чувств и 0–4 ответы опроса в общий «психологический индекс». Значения показываются раздельно, без вымышленных баллов.
- Вся обработка локальная, новая персональная информация не сохраняется; старые записи и анкеты не удаляются.
- Для параллельной установки отдельного тестового APK используй пакет `ru.tishe.app.super22`. Он не видит данные других установок (`ru.tishe.app`, `ru.tishe.app.preview` и `ru.tishe.app.preview21`).
- Готовые APK прошли CI-компиляцию, JUnit и Android Lint. Поведение на физическом телефоне требует отдельной проверки.

## Предыдущее обновление — 0.21.0

- Исправлен непонятный результат режима «Начальный · 40»: теперь автоматически видны **шесть шкал** по ответам с числовыми значениями и отдельной радар-диаграммой.
- Результаты отображаются вверху «Тестов» и в «Эмоциональном компасе» сразу после расчёта; повторного прохождения не требуется **при наличии ответов в этой же установленной копии приложения**.
- Шкалы по ответам за прошедшие семь дней отделены от 18 ручных отметок текущих чувств. Приложение не подменяет самоотчёт пользователя догадками.
- Добавлены пять тестов на 40 ответов, пересчёт, неполные данные, диапазоны и независимость тематик.
- **ВНИМАНИЕ: установка:** отладочные APK из разных GitHub Actions подписаны разными сертификатами. Они НЕ обновляются поверх прежних установок с сохранением данных. Не удаляй текущую установку с дневником и 40 ответами ради версии 0.21.0.


- **Защита при ошибках записи:** изменения зашифрованного документа теперь делаются в глубокой копии, а не в общем закешированном объекте `JSONObject`.
- Только после успешного сохранения новый JSON становится текущим. При исключении из шифрования или отказе записи исходный документ остаётся неизменённым в памяти.
- Отдельные JUnit-тесты проверяют отказ диска, исключение при изменении JSON, вложенные списки дневника и сохранность соседних полей.
- Схема хранения, Android Keystore alias, название пакета, дневник и существующие тесты не изменяются.
- Важно: это **улучшение надёжности**, а не гарантия восстановления данных при поломке телефона или потере Keystore. На физическом устройстве отказ хранилища пока не воспроизводился.
- Две APK и новый [полный архив исходников](https://github.com/Caprifan2078/tishe-android-/actions/workflows/export-source-v020.yml) формируются автоматическими сценариями GitHub.


- При первом открытии **не требуется тест** — сразу доступна главная.
- 30 прежних маршрутов практик доступны через новый поиск и фильтр по эмоциям.
- Есть фильтр коротких практик, понятные описания и пустое состояние поиска.
- Новое **«Избранное»**: отмечай упражнения звёздочкой и открывай их через отдельный фильтр.
- Избранные практики сохраняются локально в прежнем зашифрованном документе; дополнительные разрешения и интернет не требуются.
- **Поиск по истории дневника**: поиск по русскому тексту и названиям эмоций, фильтр по чувству и за последние 30 дней.
- **Редактирование существующих записей**: отдельное окно для изменения текста, эмоции и интенсивности, с явным сохранением и отменой.
- Старый текст остаётся на месте до успешной записи в AES-GCM-хранилище. Редактирование не требует интернет и не записывает текст в Android SavedState.
- Добавлены тесты на сохранность соседних записей, ограничение длины текста, дубликаты timestamp и отсутствие записи.
- Фильтры не удаляют записи и не меняют зашифрованные данные. Поисковый запрос не сохраняется в Android SavedState.
- При сохранении список ограничен 30 маршрутами, а неизвестные или удалённые маршруты игнорируются.
- Исправлен поиск склоняемых русских слов, например «границы» → «Мастерская границ».
- Сохранены существующие дневник, эмоциональный компас, игры, уроки и добровольные тесты.
- Не изменяются идентификатор основного пакета и формат AES-GCM-хранилища.

## Сборки APK

- [Обычный APK](https://github.com/Caprifan2078/tishe-android-/actions/workflows/build-apk.yml)
- [Отдельная тестовая версия](https://github.com/Caprifan2078/tishe-android-/actions/workflows/build-preview-apk.yml) с пакетом `ru.tishe.app.preview`: её можно установить параллельно старой, не удаляя существующие записи.

Открой успешный запуск Actions, затем артефакт `Tishe-Android-*-APK` и извлеки `app-debug.apk`. Это отладочные версии. **Не удаляй старую установку с личными данными** ради обновления APK с другой подписью.

В CI обязательны `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug` и проверка Android-метаданных. Успешная сборка не заменяет тестирование на реальном устройстве.
