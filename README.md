# Тише — Android

Тише — приложение для эмоциональной самопомощи и обучения эмоциональной грамотности.

## Версия 0.15.0 — понятный старт

- Приложение **сразу открывает главную страницу**. Первичная анкета больше не обязательна.
- Видны быстрые действия: упражнения, карта эмоций, дневник и школа эмоций.
- Кнопка «Мне сейчас тяжело» открывает помощь без тестов.
- Добровольная настройка рекомендаций доступна с главной и из раздела помощи.
- Обновлены цвета, крупные подписи и оформление главного экрана.

## Получение APK

Открой [GitHub Actions](https://github.com/Caprifan2078/tishe-android-/actions/workflows/build-apk.yml) и выбери успешную сборку. В разделе Artifacts скачай **Tishe-Android-debug-APK**. Внутри ZIP находится `app-debug.apk`.

Приложение компилируется с помощью Android SDK на GitHub Actions. Это тестовый APK, а не релиз из Google Play. Подпись debug-сборки может различаться между запусками; если Android сообщает о несовместимой подписи, не удаляй установленное приложение без резервного копирования данных.

**Безопасность:** исходники проекта доступны публично, личные записи пользователей не добавляются в репозиторий. «Тише» не проводит медицинскую диагностику и не заменяет помощь специалистов.
