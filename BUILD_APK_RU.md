# Получение APK «Тише» с телефона

1. Скачайте готовый файл `source.zip` из чата ChatGPT, **не переименовывайте** его.
2. На странице репозитория нажмите **Add file → Upload files**. Если на телефоне кнопки нет, откройте GitHub в браузере и включите «Версия для ПК».
3. Выберите `source.zip`, подтвердите **Commit changes** в ветку `main`.
4. Откройте вкладку **Actions → Build Tishe APK** и дождитесь результата сборки.
5. Если сборка успешна, скачайте артефакт **tishe-debug-apk**. Внутри скачанного ZIP будет `app-debug.apk`, который можно установить на Android.

Если сборка упала, откройте неудачный запуск Actions, найдите первый шаг с ошибкой и отправьте журнал в ChatGPT. Ошибки Android-компиляции пока возможны: до этого момента полный APK не собирался.

**Безопасность**: репозиторий сейчас публичный. Не загружайте свои переписки, дневники, пароли, токены, личные файлы или подписанные ключи.
